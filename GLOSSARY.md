# Initiatives Tracker

Where Element's internal initiatives stand: who is on what, each project's health, and what leads need from Matt.

## Language

**Lead**:
A person responsible for a project and its weekly check-in; a project can have several.
_Avoid_: Owner, project manager

**Stakeholder**:
A person with an interest in a project who is neither its lead nor necessarily assigned a task on it.
_Avoid_: Also involved, watcher

**Mine**:
The projects a person leads, is a stakeholder on, or has a task on; within those, only the tasks assigned to them. A focus view, not a visibility limit: everyone can still see everything.
_Avoid_: My tasks, my projects

**Ready to close**:
An open project whose tasks are all Done but whose stage hasn't been set to Done; a prompt to review it with Matt and close it.
_Avoid_: Complete, finished (those mean stage Done)

**Archived**:
A project taken off the board entirely; distinct from a project whose stage is Done, which still shows.
_Avoid_: Closed, deleted
